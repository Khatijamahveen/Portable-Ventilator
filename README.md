# Portable Ventilator Using Arduino Programming

A portable ventilator project based on **Arduino programming**, developed as an embedded-systems and biomedical engineering project.

The project demonstrates the use of Arduino-based control and programming concepts to develop a portable ventilator system. The repository contains the project documentation and a demonstration video.

> **Important:** This project is intended for **educational and prototype purposes only**. It is not a certified medical device and must not be used for diagnosis, treatment, or patient care.

---

## 📌 Project Overview

Ventilators are medical devices designed to assist patients who are unable to breathe adequately on their own. This project explores the development of a **portable ventilator system using Arduino programming**.

The Arduino microcontroller can be used as the control unit for the system, allowing programmed control of the ventilator's operating sequence and associated hardware.

The project focuses on demonstrating how **embedded systems, microcontrollers, electronics, and programming** can be combined to create a portable ventilator prototype.

---

## 🎯 Objectives

The main objectives of this project are:

* To develop a portable ventilator prototype using Arduino.
* To understand the application of microcontrollers in biomedical systems.

* To explore the integration of hardware and software in an embedded system.
* To demonstrate the working concept through a physical prototype.
* To provide project documentation for educational reference.

---

## ⚙️ System Concept

The general system consists of an Arduino-based control unit connected to the mechanical and electrical components required for the ventilator prototype.

The Arduino acts as the programmable controller. Based on the implemented program, it controls the operation of the connected hardware and coordinates the ventilation cycle.

### Basic System Flow

```text
          ┌──────────────────┐
          │     Arduino      │
          │  Microcontroller │
          └────────┬─────────┘
                   │
                   │ Control Signals
                   ▼
          ┌──────────────────┐
          │ Ventilator Drive │
          │    Mechanism     │
          └────────┬─────────┘
                   │
                   ▼
          ┌──────────────────┐
          │ Air Delivery /   │
          │ Ventilation Unit │
          └──────────────────┘
```

The exact hardware configuration and implementation details are documented in the project report included in this repository.
